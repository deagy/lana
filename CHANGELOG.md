All notable changes to Lana CLI will be documented in this file.

- Retry with exponential backoff
- Timeout support for operations
- Comprehensive test suite (33+ packages)
- Shell autocompletion (bash, zsh, fish)
- Plugin system with GitHub integration
- Knowledge store with semantic search
- GitHub/GitLab PR/MR creation
- SDLC lifecycle tracking
- Agent dispatch with role-based execution
- Interactive and noninteractive modes

- MCP client integration
- Config CLI for managing settings

- Improved CLI help text and examples
- Enhanced error messages with context
- Better terminal output formatting

- Panic recovery in critical operations
- Timeout handling for long-running operations
